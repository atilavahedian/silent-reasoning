# latent

Shared code for the silent-reasoning experiment (``): Coconut-style latent
reasoning on GPT-2 and Qwen3 bases. The contract between modules is `INTERFACE.md`; the reference being mirrored is
facebookresearch/coconut (MIT).

| module | what it does |
|---|---|
| `data.py` | Coconut JSON records, tokenization, per-stage datasets for the arms cot / no_cot / coconut / pause / coconut_no_curriculum, the batch collator, answer extraction (token-for-token equal to the reference `dataset.py`) |
| `accounting.py` | FLOPs per training sequence and per generation (prefill, latent steps, emitted tokens), sequential passes; N_ne counted from parameter shapes |
| `prosqa_gen.py` | seeded ProsQA-format generator, proof depth 3-8, controllable distractor edges, plus a record validator |
| `contamination.py` | 13-gram overlap: fraction of test questions sharing a 13-gram with train questions + steps |
| `model.py`, `train.py`, `eval.py` | latent model, training loop, batched evaluation (see INTERFACE.md) |
| `diag.py` | GPU diagnostics on the eval path (registration 7.10 items 4 and 5, A11.3 (1), A12.3): hooks on what the backbone is fed, batch isolation at B = 1 against 32, generation divergences, the scrambled pass's fed-vector distances; `band_logits` (A6.2 rule 3, critic entry 2026-10-20T12:40Z): the HF path against band [0, L] on one checkpoint, first-answer-token logits, batch shape and the same-shape swap per numerics set; `donor_answer` (A6.1 rule 4 (B)'s directional read on GSM-50k, critic entry 2026-10-20T17:36Z): `scramble` unchanged plus the pure scorer (`donor_answer_rows`, `donor_answer_summary`: the donor class, R_dir vs R_own, the 6.2-form interval, G_chg); run by the experiment's `code/run_diag.py` |

## Tests

CPU only, no downloads, under two minutes:

```bash
cd <home>/hinton && PYTHONPATH=common python3 -m pytest -q common/latent/tests
```

`tests/reference_dataset.py` is a trimmed port of the official `dataset.py` used only as the oracle for `data.py`.
Tests that need the real data skip when `data/` is absent.

## Data

```bash
python3 code/fetch_data.py --prontoqa-dir <empty dir outside the repo>
```

writes `data/{prosqa,gsm,prontoqa}_{train,valid,test}.json` (gitignored; sources under `data/raw/`) and records the
URL, commit, SHA-256, byte size and record count of every file in
`configs/data_manifest.json`. ProntoQA is regenerated by running the pinned
asaparov/prontoqa generator (needs numpy and scipy). Overlap: `PYTHONPATH=common python3 -m latent.contamination
data/prosqa_train.json data/prosqa_test.json`.
